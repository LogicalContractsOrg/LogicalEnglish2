# Español Lógico

Español Lógico es un lenguaje natural controlado basado obviamente en el Español que se habla, lee y escribe en España y Latinoamérica, pero controlado como hemos aprendido con Logical English. Es un proyecto experimental pero suficientemente robusto para ofrecerse como lenguaje de programación y representación de conocimientos en Español. 

Ejemplos inciales en español: alicia, ciudadanía británica, conjuntos y biología de las aves.
