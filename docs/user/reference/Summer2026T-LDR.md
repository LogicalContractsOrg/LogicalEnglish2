# Summer "2026 LE2 TLDR": what the language gained, 1 July – 12 October 2026

*One table per language. Each row gives a construct, what it says, the example or source that pulled it into the language, and an example that shows it. Each link opens the example in the public editor: le2.logicalcontracts.com for Logical English (LE), lps2.logicalcontracts.com for LPS (Logic Production Systems) and LE for LPS. The full rules are in [language.md](language.md) (LE), [lps-target.md](lps-target.md), and LPS2's `le-for-lps.md` and `lps.md`; the section is given in brackets.*

## LE for LPS and LPS

LE for LPS itself arrived in this period (25 July, milestone M8). It is Logical English that describes change over time and runs on the LPS engine. Its base came from the LE1 rock-paper-scissors programs of the CLOUT workshop.

| Construct | What it says | What pulled it in | Example |
|---|---|---|---|
| The base: `the target language is: lps.`, the event / action / fluent sections, `initially`, `at T` / `from T1 to T2`, `when … then` (causal laws), `if … then` (reactive rules), `the goal is that`, timed scenario events [le-for-lps §1–§5] | An LPS program written in sentences | The LE1 rock-paper-scissors programs | [rock_paper_scissors_minimal](https://lps2.logicalcontracts.com/ide?example=le/rock_paper_scissors_minimal.le), [fire_simple](https://lps2.logicalcontracts.com/ide?example=le/fire_simple.le), [prospective_goat](https://lps2.logicalcontracts.com/ide?example=le/prospective_goat.le) |
| Times left out | A sentence takes its time from where it stands [§3.1] | Shorter Solidity twins | [fire_simple](https://lps2.logicalcontracts.com/ide?example=le/fire_simple.le) |
| `; 0 by default` on a fluent (LPS: `defaults([…])`) | A fluent's value when nothing has set it [§2; lps.md §3a] | The zero of a Solidity mapping | [le/token.le](https://lps2.logicalcontracts.com/ide?example=le/token.le) |
| `the knowledge base X extends B, C.`; `this law replaces law L of B.` | One program built on others, overriding laws and constraints [§1.1] | Solidity contract inheritance | [le/fee_token.le](https://lps2.logicalcontracts.com/ide?example=le/fee_token.le) |
| Lists in laws and observations (`alice airdrops 5 to [bob, carol] at 3`) | One action applied to each member of a list [§4] | The Solidity airdrop | [le/token.le](https://lps2.logicalcontracts.com/ide?example=le/token.le) |
| Joined effects: `then A and it is not the case that B` | One sentence gives several laws [§3.4] | Reviews by Epilog and Drools experts | [l4/party_example](https://lps2.logicalcontracts.com/ide?example=migration/l4/party_example/party_example.le) |
| Budget templates: `the gas of *an action* is …`, `the code size of the contract is …`, `the largest whole number is …` | Deployment budgets that Deploy as Solidity checks [§3.10] | Ethereum's gas and contract-size limits | none public (tested in lpsPlus) |
| `:- lps_engine(planning, …)` and `achieve G.` | Declarative planning [lps.md §14] | LPS2's plan, its one deliberate addition to LPS | [start/goat_declarative](https://lps2.logicalcontracts.com/ide?example=start/goat_declarative) |
| `display3d/2` | A 3D picture of the state [lps.md §18a] | The IDE's 3D pane | [start/blocks3d](https://lps2.logicalcontracts.com/ide?example=start/blocks3d) |

*Not listed, because they are not syntax:* libraries (`lib/temporal.le`, `lib/deontic.le`, `lib/rounding.le`), verifier warnings, changes of meaning (the minimum of nothing now fails; a reactive rule triggered by an event acts after the event ends), and the readers of other languages. *A gap:* `; composite` (another word for `; prepositional`) has no example.
