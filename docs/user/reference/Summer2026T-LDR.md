# Summer "2026 LE2 TLDR": what the language gained, 1 July – 12 October 2026

*This document has one table for each language. Each row gives a construct (a new part of the language) and what the construct says. The row also gives the example or source that caused the addition, and an example that shows the construct. Each link opens the example in the public editor. The public editor is le2.logicalcontracts.com for Logical English (LE), and lps2.logicalcontracts.com for LPS (Logic Production Systems) and LE for LPS. Refer to [language.md](language.md) (LE), [lps-target.md](lps-target.md), and the LPS2 documents `le-for-lps.md` and `lps.md` for the full rules. The section number is in brackets.*

## LE for LPS and LPS

LE for LPS came in this period (25 July, milestone M8). LE for LPS is Logical English that describes change over time. It runs on the LPS engine. Its base came from the LE1 rock-paper-scissors programs of the CLOUT workshop.

| Construct | What it says | What caused the addition | Example |
|---|---|---|---|
| The base: `the target language is: lps.`, the event / action / fluent sections, `initially`, `at T` / `from T1 to T2`, `when … then` (causal laws), `if … then` (reactive rules), `the goal is that`, timed scenario events [le-for-lps §1–§5] | An LPS program written in sentences | The LE1 rock-paper-scissors programs | [rock_paper_scissors_minimal](https://lps2.logicalcontracts.com/ide?example=le/rock_paper_scissors_minimal.le), [fire_simple](https://lps2.logicalcontracts.com/ide?example=le/fire_simple.le), [prospective_goat](https://lps2.logicalcontracts.com/ide?example=le/prospective_goat.le) |
| Times not written | A sentence gets its time from its position [§3.1] | Shorter Solidity twins | [fire_simple](https://lps2.logicalcontracts.com/ide?example=le/fire_simple.le) |
| `; 0 by default` on a fluent (LPS: `defaults([…])`) | The value of a fluent when nothing has set the value [§2; lps.md §3a] | The zero of a Solidity mapping | [le/token.le](https://lps2.logicalcontracts.com/ide?example=le/token.le) |
| `the knowledge base X extends B, C.`; `this law replaces law L of B.` | One program built on other programs. The program can replace their laws and constraints [§1.1] | Inheritance of Solidity contracts | [le/fee_token.le](https://lps2.logicalcontracts.com/ide?example=le/fee_token.le) |
| Lists in laws and observations (`alice airdrops 5 to [bob, carol] at 3`) | One action applied to each member of a list [§4] | The Solidity airdrop | [le/token.le](https://lps2.logicalcontracts.com/ide?example=le/token.le) |
| Joined effects: `then A and it is not the case that B` | One sentence gives more than one law [§3.4] | Reviews by experts in Epilog and Drools | [l4/party_example](https://lps2.logicalcontracts.com/ide?example=migration/l4/party_example/party_example.le) |
| Budget templates: `the gas of *an action* is …`, `the code size of the contract is …`, `the largest whole number is …` | Deployment budgets that **Deploy as Solidity** checks [§3.10] | The limits of Ethereum for gas and contract size | none public (tested in lpsPlus) |
| `:- lps_engine(planning, …)` and `achieve G.` | Declarative planning [lps.md §14] | The plan of LPS2. This is the one addition to LPS that LPS2 made on purpose | [start/goat_declarative](https://lps2.logicalcontracts.com/ide?example=start/goat_declarative) |
| `display3d/2` | A 3D picture of the state [lps.md §18a] | The 3D pane of the IDE (the program editor of LPS2) | [start/blocks3d](https://lps2.logicalcontracts.com/ide?example=start/blocks3d) |

*Not in the tables, because they are not syntax:* libraries (`lib/temporal.le`, `lib/deontic.le`, `lib/rounding.le`), verifier warnings, changes of meaning, and the readers of other languages. Two changes of meaning are: the minimum of nothing now fails, and a reactive rule that an event starts acts after the event ends. *A gap:* `; composite` (another word for `; prepositional`) has no example.
